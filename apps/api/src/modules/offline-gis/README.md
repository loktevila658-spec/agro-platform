# Offline GIS delivery (WP49-029)

Farm owns Field/FieldSeason; GIS owns geometry. Delivery queries these application services with current trusted tenant/org/site/field scope. It writes only `offline_gis` derived selection, projections and immutable audit. Real Tasks from WP49-031 use their unchanged command/queue contract.

Trusted composition installs `OfflineGisRegistry` once. Missing policy denies. `scope(actor, action)` must evaluate the current role and organization/site/field constraints; absent field/site filters mean organization-wide access, empty filters mean no matching rows. Supply a versioned rendering tolerance and explicit O1 grant TTL (existing platform maximum seven days). No role/default data/provider/credentials are seeded. Public basemap styles must be licensed for offline use, free of credentials and immutable for the declared style/source version. A missing source leaves explicit vector-only availability.

One active package per registered device uses that device UUID as the aggregate ID. OfflineGis.Select/Refresh@1 reuse SyncService authorization, version guards, immutable command identity, receipts and atomic feed. Each field has a separate bounded projection; the manifest lists expected projection IDs/version. Historical geometry pins remain exact; newer approved sources mark staleness rather than changing the pinned geometry. A newly selected source/region resets incompatible native cache before download.

Farm/GIS/Land events use the real dispatcher/inbox consumer. Event delivery computes actual deltas, calls public SyncService.appendChanges to acquire its owned feed ordering lock, then verifies/locks the previously read package version before owned writes. A concurrent selection causes transaction rollback/retry, never a stale overwrite or direct platform-table write. Scope/source withdrawal emits PURGE atomically. Permission changes must advance registered-device scope using the existing platform contract so clients rebootstrap; every pull also rechecks current read permission. Selection replay rechecks current scope before returning an old receipt.

Server schema15->16 expands derived storage. Mobile1/2->3 preserves existing queues, receipts, audit, attachments and cursors. Local fields/manifests stay in encrypted workspace storage; native global cache holds only approved public basemap resources and opaque region metadata. External assets are marked before native creation; a successful native cleanup callback is required before shared wipe/account switch. PERSONAL logout retains encrypted intent but clears native assets. Failure blocks switching accounts.

No sync schema/retry protocol, canonical Task semantics, foreign business writes, satellite/agronomy/ledger behavior, provider credentials, frozen manifests or release profile changes. Android is the current native target; iOS is not shipped by this WP. Native HTTP fixture uses the separately owner-approved debug-only loopback policy. Release remains strict. Actual native acceptance is still pending until exact CI passes.

Pinned native limitation: Android maplibre_gl0.27.1 returns ResumeRegionError when its observer was lost after process restart. The adapter then uses the plugin-supported restart of the same partial region definition; public basemap resources may download again and the UI says so. A complete cached region is read without requesting a restart. Vectors/tasks/commands remain encrypted and unaffected; no native byte-range/process-kill certification is claimed.
